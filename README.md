# Heartwood Bingo

A collaborative, team-based bingo game manager for Heartwood events. Supports custom board sizes, image uploads, rarity, point scoring, and team play.

## Folders

- `backend/` - Node.js/Express API, models, and utilities
- `frontend/` - React app for board management and gameplay

## Getting Started

1. **Install dependencies**  
   From the root, run:
   ```bash
   npm install
   ```

2. **Start the backend**  
   ```bash
   npm run dev
   ```

3. **Start the frontend**  
   Open a new terminal, then:
   ```bash
   cd frontend
   npm install
   npm start
   ```

4. **Open in browser**  
   Visit [http://localhost:3000](http://localhost:3000)
